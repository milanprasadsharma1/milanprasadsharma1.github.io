# Milan Prasad Sharma — Personal Portfolio

GitHub Pages-ready personal portfolio website.

## Files
- `index.html` — website
- `milan-profile.png` — profile photo
- `.nojekyll` — GitHub Pages configuration

## Publish
Create a GitHub repository named:

`YOUR-GITHUB-USERNAME.github.io`

Upload all files from this folder to the repository root, then enable:
Settings → Pages → Deploy from a branch → main → / (root)
